# Security Policy

## Supported Versions

Security fixes target the latest released version of `storeit`.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by opening a GitHub security
advisory for this repository. Include:

- affected versions or commits;
- a minimal reproduction or proof of concept;
- expected impact;
- any known mitigations.

Do not disclose exploitable details publicly until a fix or mitigation is
available.
