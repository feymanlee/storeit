# Code of Conduct

This project follows a simple standard: be respectful, direct, and constructive.

## Expected Behavior

- Use welcoming and inclusive language.
- Focus feedback on the work, not the person.
- Assume good intent while still being precise about technical concerns.
- Respect maintainers' time by keeping issues and pull requests actionable.

## Unacceptable Behavior

Harassment, personal attacks, discriminatory language, and deliberate disruption
are not acceptable in project spaces.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation
when behavior harms the project or its contributors.
